01 / Start here

Getting Started
three moves.

Install the package, make a thing, give it a heartbeat. Objects appear as soon as you create them.

01

Install

Get the package from PyPI.

pip install simple-graphics-lib
02

Compose

Shapes register themselves in the scene.

from simple_graphics import *

ball = Circle(140, 120, 24,
              color="#ff6b4a")
03

Run

Decorators connect your logic to the loop.

@on_tick
def update():
    ball.x += 2

run(400, 300)
A complete first scene

Paste this into a file and run it with Python.

from simple_graphics import *

ball = Circle(80, 120, 24, color="#ff6b4a")

@on_tick
def move():
    ball.x += 2
    if ball.x > 400:
        ball.x = 0

run(width=400, height=240, caption="A small beginning")

02 / The visual vocabulary

Drawing Shapes

Every shape is a live Python object. Change its properties inside an event and the next frame reflects it.

Rect

Rect(x, y, width, height)

Rectangles, panels, paddles, cells, and buttons.

rotate · draggable · outline

Circle(x, y, radius)

Round bodies for balls, planets, and markers.

area · collision · draggable

Polygon

Polygon(points)

Build custom silhouettes from a list of vertices.

rotate around a point

Line(points, width=10)

Connect points into paths, hands, and boundaries.

03 / Give it a heartbeat

Event Handling

Use a decorator to say when a function should run. Simple Graphics handles the Pygame event loop for you.

event.py
@on_tick
def update():
    ball.x += velocity
    ball.y += gravity
The default callback runs once every frame.run()

The compact
reference.

These are the pieces you will reach for most often while building.

Scene controls

run(...)Start the window and main loop.
set_bg(color)Set the background color.
clear_screen()Remove every shape.
erase(shape)Remove one shape.
is_colliding(a, b)Check whether two shapes overlap.

State helpers

mouse.x / mouse.yRead the current pointer position.
game.any_nameStore shared mutable game state.
Group(a, b, ...)Move and query shapes together.
shape.visibleKeep a shape in the scene but hide it.
shape.rotate(angle)Rotate supported shapes in degrees.
